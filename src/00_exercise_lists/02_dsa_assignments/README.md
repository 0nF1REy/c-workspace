# Tarefas de Estruturas de Dados e Algoritmos

Neste diretório contém uma coleção de exercícios e implementações desenvolvidas em C, relacionados a estruturas de dados e algoritmos. Os códigos-fonte individuais seguem um padrão de nomenclatura para facilitar a organização.

Também há um arquivo principal em C que reúne os códigos em um único programa, permitindo acessá-los por meio de um menu interativo.
